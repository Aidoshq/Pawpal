# PawPal 🐾
PawPal is a simple Android application designed to help pet owners organize information about their pets and manage daily pet care tasks.

## Project Idea
Pet owners have many daily responsibilities such as feeding, walking, grooming, giving medicine, and scheduling veterinary visits. It can be difficult to keep track of all these activities, especially when a person has more than one pet.

PawPal provides a simple way to store pet information and manage care tasks in one place.

### Target Audience
The target audience is pet owners who want an easy and organized way to manage their pets and daily care routines.

## Main Functionality
- Create a pet profile with name, type, age, and breed.
- View a list of saved pets.
- View detailed information about a selected pet.
- Add a new care task for a pet.
- Edit and delete existing care tasks.
- Mark care tasks as completed.
- View all care tasks for a selected pet.
- Store pet profiles and care tasks locally on the device.
